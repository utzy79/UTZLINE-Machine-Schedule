Pick the same top-level Projects folder used by every other UTZLINE app (Site Measure, Viewer, Install ITP, Manufacture ITP, Delivery ITP, Projects, Scheduler). Machine Schedule reads their data read-only, and keeps its own cut-status records (Carcase/Colour board/Solid Surface, under each project's "Project Saves/Machining Flags") alongside it -- once every applicable cut is Done or N/A, it marks the item "machined" in the same shared status records they already all read. It also shares their name+PIN registry. Nothing about those apps changes.
